CASE 03 · SIMULATION / TOOLING

RustTeamSim

경기와 승강, 선수의 성장·은퇴를 다루는 리그 시뮬레이션입니다. Rust와 Unity/C#으로 개발하고 Spring Boot로 콘텐츠 편집 도구를 만들었습니다.

시뮬레이션, 게임 화면, 편집 도구

구현담당 책임
Rust리그·매치·선수 생명주기, 병렬 분석과 리포트
Unity / C#도메인 모델 포팅, 애플리케이션 흐름과 UI
Spring Boot선수와 팀 데이터를 브라우저에서 편집

선수와 팀 데이터 편집

선수를 검색해 능력치와 성장 단계를 바꾸고, 팀별 선발과 벤치를 배정합니다. 같은 선수가 중복 배정되거나 없는 선수·팀을 참조하면 저장 전에 알려줍니다.

편집 중 원본 파일이 외부에서 바뀌면 덮어쓰지 않고 다시 불러오도록 안내합니다.

선수 생명주기

30개 팀을 3개 티어로 나누고 스플릿마다 경기와 승강을 처리합니다. 2개 스플릿을 1년으로 묶고 연간 성장과 재분배는 연말 경계에서 수행합니다. 경기와 시즌 통계는 리포트로 남겨 팀 구성과 선수 성장에 따른 변화를 살펴볼 수 있습니다.

소스 코드

  • Unity 포팅과 콘텐츠 편집 도구
