Unity Client + Rust Server

MCsFPTest1

전투의 판정과 상태 적용, 화면 표현을 분리하고 같은 도메인을 서버 권위 네트워크 런타임으로 확장한 전투 RPG 시스템입니다.

로컬에서는 Resolver가 결과와 Mutation을 만들고 단일 적용 경로가 상태를 변경합니다. 네트워크에서는 클라이언트가 의도만 전송하고 Rust 서버가 최종 상태를 결정하며, 비동기 수신 메시지는 큐를 거쳐 Unity 메인 스레드에서 상태와 표현에 순서대로 반영됩니다.

Rust Simulation + Unity/C# Port + Spring Boot Tool

RustTeamSim

30개 팀, 3개 티어의 리그 시뮬레이션을 Unity/C#으로 옮기고, 디자이너가 콘텐츠 그래프를 안전하게 수정할 수 있는 로컬 편집 도구까지 연결했습니다.

Rust 원본의 경기·승강·선수 생명주기 모델을 Unity 애플리케이션으로 포팅했습니다. 별도로 추가한 Spring Boot 도구는 Unity가 읽는 content_graph.json v4를 브라우저에서 직접 편집하며, 선수 검색과 능력치·성장 단계 수정, 팀별 5역할 선발·벤치 배정을 지원합니다.
